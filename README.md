# NUCLIC - Nuclear innovation consultancy website

A modern, responsive website for NUCLIC - Nuclear innovation consultancy.

## Features

- One-page design with smooth scroll effects
- Fully responsive (mobile, tablet, desktop)
- Modern UI with animations and interactions
- Custom NUCLIC logo with animations
- Contact form with validation
- Preloader animation

## Technologies

- HTML5
- CSS3 (Variables, Flexbox, Grid, Animations)
- Vanilla JavaScript (no frameworks)
- SVG for graphical elements

## Usage

1. Open `index.html` in a modern web browser (Chrome, Firefox, Safari, Edge)
2. The website is fully functional without an internet connection, as all assets are built-in with SVG and have no external dependencies

## Structure

- **index.html** - The complete website HTML structure
- **styles.css** - All styling for desktop and mobile
- **script.js** - JavaScript for interactions and animations
- **nuclic-logo.svg** - SVG version of the NUCLIC logo

## Design Features

- Dark blue background for a professional appearance
- NUCLIC logo and atom theme throughout the design
- Animated transitions between sections
- Timeline display for projects
- Card system for expertise and partners
